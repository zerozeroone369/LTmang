# UniConnect Client App (Web / Mobile) — Workspace dành cho Thái

Đây là thư mục dành cho thành viên **Thái (Frontend Developer)** phát triển giao diện Client cho sinh viên (Nhiệm vụ 9 & 10):
- **Nhiệm vụ 9:** Login, Register, Hồ sơ cá nhân, Bảng tin thông minh, Bài viết chi tiết, Cộng đồng (Trường/Khoa/Ngành/Khóa/Lớp).
- **Nhiệm vụ 10:** Tài liệu học tập, Hỏi đáp Q&A, Nhóm học, Tab Campus và Thông báo Realtime (Socket.io client).

## Tài liệu tích hợp sẵn từ Backend (Tú Anh):
- **Base URL Local:** `http://localhost:4000/api`
- **Swagger UI:** `http://localhost:4000/api-docs`
- **Postman Collection:** [`../docs/postman_collection.json`](../docs/postman_collection.json)
